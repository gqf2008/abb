## 需求清单（owner 逐轮确认）

| # | 能力 | 关键口径 |
|---|---|---|
| 1 | **模型选择** | **按会话**生效；下拉**只列「设置 → 供应商」里已配置的模型**；切换从下一条消息起生效，不改历史 |
| 2 | **新建会话** | 在 **输入区左侧竖排**（`＋` 图标，文案作 tooltip） |
| 3 | **设置** | 标题栏 `⚙`，唤起现有设置窗 |
| 4 | **Markdown 渲染** | 标题/列表/粗体/行内码/代码块/引用/表格/链接/图片 + 内嵌音视频；**本地路径与 `http(s)` 链接都支持** |
| 5 | **附件与剪贴板** | **⌘V 粘贴 / 拖拽**接收 图片·音视频·文件；📎 **可一次多选**；**随消息一起发送**（不单独发）|
| 6 | **待发附件（输入框内）** | 在输入框内顶部；**最多展示 3 个，其余折叠成 `+N`**；可展开、逐个 ✕ |
| 7 | **会话历史** | 新建会话**保留旧会话**；标题栏「🗂 会话」下拉可切回历史继续聊 |
| 8 | **气泡交互** | 单击＝开/收对话框；按住拖＝移动（位置记忆）；**按下有反馈**（缩 0.9 + 墨黑描边）|
| 9 | **窗口跟随气泡** | 对话框锚定在气泡旁（间距 10px），拖动气泡窗口一起动；靠屏边自动翻到另一侧不出屏 |
| 10 | **流式输出** | 打字机效果，尾部光标；生成中显示「正在输入」+ **⏹ 停止** |
| 11 | **思考/正文分离** | 思考过程独立成块、**默认折叠**（标题显示耗时），点开看推理；正文另起、正常渲染 |
| 12 | **Token 占用** | 状态行显示本会话 **已用/上限**（如 `12.4K/128K`）+ **百分比** + 小进度条；≥70% 橙、≥90% 红；悬停看精确值 |
| 13 | **气泡随窗隐藏** | 点气泡 → 弹出对话框并**隐藏气泡**；关窗后气泡**重新出现**（D 批） |

其它已确认口径：对话区是**单一内容区**（一轮 = 角色名 + 内容，无独立外框），整体滚动、新消息贴底。

## 实现分批判定

- **A 模型选择（会话粒度）+ 会话历史**
  - 本批 GUI 落位（与稿子的有意差异，D 批收口）：`＋ 新建会话` 暂放**输入行**、
    会话/模型下拉暂放**工具行**（`PixelTitleBar` 不能塞子元素）；D 批再改成稿里的
    「输入区左侧竖排图标 + 标题栏会话下拉」。
- **B Markdown + 媒体（本地路径 / http(s)）内嵌渲染**
- **C 附件与剪贴板**（⌘V / 拖拽 / 多选 → 落 `~/.agent-bridge/workspaces/syschat/` → **路径**写进 prompt）
- **D 输入区新布局**（左竖排图标、框内待发附件 3+N）+ **气泡按下反馈 / 窗口跟随**
- **E 流式输出 + 思考/正文分离 + Token 占用**（动 `runtime` harness / ACP 适配层，最重）

### E 批的两个前置（实核过的技术债）

1. **流式分片没有回传**：执行层走 `runtime::oneshot::oneshot_turn`，只回调最终文本
   （`pool::PromptResult::final_text`），ACP 的 `agent_message_chunk` / thought 分片未转发。
   打字机 + 思考分离必须改适配层，并**区分正文 chunk 与思考 chunk**。
2. **Token 用量与上下文长度**：
   - harness 移植时**删掉了 usage 处理**，需从 ACP 回合结果里重新取（真实 usage 优先，
     退路用 `chars/4` 估算并**标注为估算**）；
   - `providers[].model` **没有上下文长度字段**，需要内置一张「常见模型 → 上下文」映射兜底，
     并允许在「设置 → 供应商」覆盖（`context_window`）。

### 附件喂给 agent 的方式（已确认）

复制/选择/拖入的文件**先落盘**到 `~/.agent-bridge/workspaces/syschat/`（沿用现有「bot 工作区」约定），
再把**文件路径**随消息文本一起进 prompt（agent 自己按需读取），不把二进制塞进 prompt。
