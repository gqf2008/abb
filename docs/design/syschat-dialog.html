v16：音视频内联播放器 / 剪贴板支持图片 / 待发附件可退格删除（2026-10-16 owner 口径）
  1. 音视频 = 内联播放器（v15 的「一行链接」作废）：与稿上方 mock 一致——卡片（2px 描边）+ 海报帧/画面 + 播放控件 + 下方 .cap 说明条。 控件按稿的播放器还原：▶/⏸、进度条（可拖）、当前时间/总时长、音量、全屏（先做 ▶/⏸ + 进度 + 时间，音量/全屏随其后）。
    实现路径（Slint 没有 audio/video 元素）：视频用本机 ffmpeg 把帧以 rawvideo/rgba 流式喂给 Slint（Image::from_rgba8 + Timer 翻帧，内存有界、不落整段帧到磁盘）；音频用 afplay 播放 + 自绘进度（ffprobe 取时长）。海报帧 = ffmpeg -frames:v 1 抽首帧并缓存。
  2. 剪贴板要支持图片：截图工具（如 PixPin）把**图片**放进剪贴板，不是文件 ⇒ ⌘V 现在只认文件 URL，图片粘不进来。口径：⌘V 依次尝试 ①文件 → ②剪贴板图片（PNG/TIFF），图片写进附件目录后与 📎/✂ 走同一条待发路径。
  3. 待发附件可退格删除：输入框为空（或光标在末尾且没有可删字符）时按 Backspace ⇒ 删掉**最后一个待发附件**（再按继续往前删）；✕ 徽标仍然可用。状态行报「已移除附件 X」。
v15：底色统一 / 思考块 1+10 行 / 生成贴底 / 单线分割 / 左右分栏对齐（2026-10-16 owner 口径）
  1. 块不要独立底色：公式块（以及其它「数据表达式」类块）的背景必须与消息区一致（--panel）；稿里那些 .media/details.think 的 var(--bg) 只用于「有框的卡片」，公式块没有框、也没有底色（现在看起来发黄 = 错）。
  2. 思考块：默认关闭（生成中也不自动展开）。关闭态只有标题那一行；生成中标题下方滚动显示最新的那一行思考（一行高的「打字机窗口」，不把页面撑开）；展开后正文最多 10 行高，超出块内滚动并始终贴底（1 + 10 的上限）。
  3. 生成中（含思考部分）始终贴底：流式输出时视图必须跟着内容走（推翻 v14 加的「只有已贴底才跟随」——那会让生成看起来不是流式）。
  4. 中继（内容区 ↔ 输入区）分割区只留一根线：那条 2px 线之外不要再出现第二条观感的分界（分割条底色与下侧输入区同色，不要靠色差造出「第二条线」）。
  5. 左右分栏对齐：用户输入的消息靠右、怹（AI）的输出靠左（角色名与正文一起）。
  6. 音频 / 视频也是「一行」：与图片同口径——**不做带边框的卡片、不做按钮**，只给一行可点的提示（点它用系统播放器打开）。
    （受限：Slint **没有 `audio`/`video` 元素**，稿里的内联 <video controls> 做不到；退而求其次就是「一行链接」，不是卡片。）

v13：markdown / 数学渲染规格（2026-10-16 回写，实现已交付）
  1. 标题：h1 18px / h2 15px / h3 14px；段落 13px、行高随字体默认。
  2. 代码：块级＝深底 #1c1a17 + 浅字 #f6efe1、圆角 6、可选语言标注；行内＝暖底等宽等（由 Slint StyledText 渲染，没有稿里那条 1px 描边——该样式 Slint 不暴露，要一致只能自绘行内码）。
  3. 引用：左侧 4px 暖黄强调条 + 暖底，只圆右侧两角（0 6px 6px 0）。
  4. 图片：按源宽高比自适应（contain，高夹 120–360px；SVG 读 viewBox 拿比例）。遵守 markdown 规范：只有图本身——无边框、无 .cap 说明条、无「打开」按钮（owner 2026-10-16 口径，推翻本稿早先的 .media 卡片样式）；加载不出来时给一行可点的提示（🖼 alt（图片打不开）），不做卡片/按钮。v14 起：图片**右键 = 复制图片**（见下），左键不做事、不再给「打开」。
  5. 表格：整表一个块（列宽按内容估、一个横向滚动条）；行高显式给（= 该行最高格 + 8px，行与行紧贴无缝隙）；列对齐按 |:---|:--:|--:|；单元格里的公式也真排版（与段落同一套混排）。
  6. 数学：块级 $$…$$ 由 KaTeX 的 Rust 移植（ratex）出 SVG；行内 $…$ 与文字同一套 parley 混排（文字仍由 Slint 画、公式是图）；排不出来一律回落等宽源码，绝不吞字。含行内公式的段落不可拖选（整段是定位好的片段），宽度变化会重排。
  7. 思考块：浅暖灰 2px 边框 #d9cdb4、标题左对齐 ▸ 思考 · 用时 3.2s（进行中 思考中）；展开态的虚线分隔做不了（Slint 无 dashed 边框）。
  8. 动作行字形：📋 复制 / ↻ 重新生成 / 🔊 朗读。原稿的 ⧉(U+29C9)/⟳(U+27F3) 系统 UI 字体没有（真机渲染成方框，2026-10-16 owner 截图），故替换为能渲染的等价字形。
  9. 已知未对齐：① 单元格内的 <br> 不换行（仍是字面量）；② 远程图片需联网 + 缓存，离线走「打开」卡片；③ 表格列宽按字符估算（且看的是含 TeX 源码的单元格）⇒ 公式列可能偏宽。
